# AudiPlay — HTML5 Audio Player

AudiPlay is a small HTML5 audio player library that can be applied to native `<audio>` elements with the `audiplay` class.

## Demo

Open [`index.html`](./index.html) for an interactive demo. The repository includes a sample audio file and player assets.

## CDN integration

```html
<audio controls class="audiplay">
  <source src="https://cdn.jsdelivr.net/gh/sh20raj-backup/AudiPlay@main/Ark.mp3" type="audio/mpeg">
</audio>
<script src="https://cdn.jsdelivr.net/gh/sh20raj-backup/AudiPlay@main/audiplay.min.js"></script>
```

The CDN URLs above point to the `sh20raj-backup/AudiPlay` repository. Pin a release or commit SHA in production if you need repeatable builds.
