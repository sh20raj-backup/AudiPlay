AudiPlay - HTML5 Audio Player

Demo audio controls with integration hosted from the backup repository.

Use class audiplay on your audio element and load the JavaScript near the end of the body.

<audio controls class="audiplay">
  <source src="Ark.mp3" type="audio/mpeg">
</audio>
<script src="https://cdn.jsdelivr.net/gh/sh20raj-backup/AudiPlay@main/audiplay.min.js"></script>
